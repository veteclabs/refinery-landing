# Refinery 과제별 신호 아이콘 (클레이 3D)

배경·그림자 없는 투명 아이콘 23종. 모든 파일이 같은 캔버스·같은 배율이라 카드에 같은 크기로 넣으면 크기가 맞습니다.

- png/  512×512 투명 PNG
- webp/ 512×512 투명 WebP (용량 작음, 권장)
- svg/  512×512 SVG — 내부에 투명 고해상도(616px) 이미지를 담은 형식. 3D 명암 때문에 순수 벡터 경로가 아닙니다.
