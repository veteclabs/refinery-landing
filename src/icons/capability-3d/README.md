# Why Refinery · "하나의 운영체제에 담긴 기능" 카드 아이콘 (3D, 아이소메트릭)

`src/icons/flow-3d/` 아이콘과 같은 스타일·같은 캔버스·같은 배율입니다.
회색 바닥판 + 흰/브랜드 파랑 조형, 안쪽 요소는 음각 디테일.

| 파일 | 카드 | 내용 |
|---|---|---|
| cap-data | 데이터 | 세 층으로 쌓인 데이터베이스 (슬롯 · 상태 표시등) |
| cap-ai | 지능 | 막대 차트의 튀는 지점을 돋보기로 들여다봄 (이상 감지 · 예측) |
| cap-ops | 운영 | 맞물린 톱니바퀴 세 개 |
| cap-trust | 신뢰 | 방패 + 체크 |

## 버전
- `cap-*` : 어두운 면(#11161C 계열)용 — 흐린 점선 큐브 + 흰 바닥 테두리
- `cap-*-light` : 흰 면용 — 큐브 점선 · 바닥 테두리를 회색 잉크 톤으로
- `cap-*-plain` : 큐브 선 없이 아이콘과 바닥판만 (어디에나)

## 크기
- `*.png` / `*.webp` : 512×512
- `*@2x.png` / `*@2x.webp` : 1024×1024
- 4개 모두 같은 캔버스 · 같은 배율이라 같은 크기로 넣으면 크기가 맞습니다.
