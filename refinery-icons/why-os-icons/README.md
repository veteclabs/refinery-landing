# 왜 운영체제인가 — 카드 아이콘 4종

페이지: /why-refinery › "왜 운영체제인가" (연결부터 판단까지 네 개의 층으로)

| 파일 | 카드 | 호버 모션 |
|---|---|---|
| os-connect | 연결 | 가운데 유리 육각 허브가 톡 튀고, 원·사각·마름모 설비가 차례로 반응 |
| os-ontology | 온톨로지 | 데이터베이스 앞 유리 관계 배지가 톡 튐 |
| os-app | 앱 | 겹친 앱 아이콘 세 장이 부채처럼 살짝 펼쳐졌다 모임 |
| os-agent | AI 에이전트 | 답 말풍선이 떠오르며 점 세 개가 차례로 통통, 질문 말풍선의 작은 별이 반짝 |

## 폴더
- light/, dark/ → svg-animated (호버 모션 SVG, 사이트용) · svg (정지) · png (512) · png64
- source/ → 생성 스크립트 (기존 시리즈와 같은 lib.js 사용)

## 적용 기준 (기존 랜딩·문서 아이콘과 동일)
- 둥글기: 헤더 버튼 비율(6/37)로 완화 · 원형 요소는 유지
- 안쪽 요소: 막대 굵기 20 알약형 · 작은 점 r14 · 기호 0.75배
- 전체 크기: 보이는 면적 통일(√면적 360, 최대 변 400) · 중앙 정렬
- 모션: animation-name 이 var(--rf-play, …) — RfIcon 컴포넌트에서 .rf-ic-host 호버 시에만 재생

## 사이트에 넣을 때
섹션 배경이 밝으므로 light 세트를 사용:
`src/icons/light/` 에 svg-animated 4개를 복사한 뒤 `<RfIcon name="os-connect" theme="light" />` 처럼 사용.
카드에 `.rf-ic-host` 클래스가 있어야 호버 모션이 재생됩니다.
